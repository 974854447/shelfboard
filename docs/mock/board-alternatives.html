看板重构 · 三个候选方案

线框图，只看结构不看样式。三者的差别是「什么在什么时候出现」—— 扛量能力就取决于这一点，而不是卡片长什么样。
A · 分列看板 + 卡内子树 + 按需关系层推荐

平时是一列列紧凑卡片，主任务的子任务缩进在卡片内部，不额外占地方； 关系线默认不画，悬停某张卡时才浮出一层连线，看完就收。

B · 大纲树 + 关系侧栏最扛量

左边一棵可折叠的树（主任务→子任务→孙任务），右边是选中任务的关系面板。 关系不用画线，用文字列表表达，所以再多也不乱。
