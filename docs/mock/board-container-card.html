这一版改了什么

样式压平了：卡片静置无阴影无渐变，主任务只靠左侧一条细线和尺寸区分， 网格减淡、去掉光晕。但内容加厚了 —— 进度、完成比、时间、标签都在卡片上。

交互分开：点卡片 = 打开任务详情，点「子任务 N」 = 展开/折叠。 抽屉里点前置任务或子任务可以就地跳过去。

点卡片是"开详情"还是"展开子任务"？三种都做了，点着试一下再定：

  • 父子脐带线：从主任务卡片背后伸向子任务，展开时「生长」出来；子任务绕在四角，空间上表示归属。
  • 前置依赖：琥珀色虚线 + 箭头标方向，线上光点流动。
  • 标签关联：绿色点线，弱关系，默认更淡。
  • 里程碑：虚线区域带圈住同一里程碑的任务（只留边框，不填充）。
  • ◉ 关系聚焦：悬停一张卡 —— 祖先链、后代、依赖方、同标签全亮；同里程碑邻居退一半；无关的退到背景。
  • ▤ 层级纵深：子任务小一档、孙任务更小更淡，不看缩进也知道属于谁。
  • ⠿ 可直接改：把手拖拽改归属、卡片四边端口拖出连线（原型里只占位，未接逻辑）。
容器卡 + 子任务环绕的视觉稿第二版。方向确认后再谈落到真实组件与分几期。
