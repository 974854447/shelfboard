## 0.2.0（2026-09-25）· M2 完成

**M2 的三项新功能全部落地**：日历视图、我的待办、全局搜索。
另外补上了设置页的收尾项、修掉一批"看着不起眼但很烦"的问题。

### 新增

- **日历（全新）**：按截止日排期，月历固定 6×7 格、周一为周首。
  - 格子上带**农历日、二十四节气、法定节假日**：放假的格子标「休」、调休上班的标「班」，
    周末、今天、选中的那天各有自己的底色与描边。
  - **可以给某一天加标记**（发版、休假、生日…）：五种颜色 + 可选备注，
    格子上是一行彩色药丸，右侧「标记」面板里就地增删。
  - 右侧面板：选中某天的任务（卡片与工作台完全一致）、逾期、本周小结、
    近 14 天负荷柱状图、项目分布、下一个假期倒计时。
- **我的待办（全新）**：把所有项目里未完成、有截止日的任务汇总到一页，
  按 逾期 → 今天 → 本周 → 以后 → 没有截止日 五组横向并排；
  每张卡片标出所属项目；做完的不再进前三组。
- **全局搜索（全新）**：任务与工单的全文检索，跨项目；**中文片段也能搜**
  （三个字以上走全文索引，两个字自动改用模糊匹配，界面会说明这次走的是哪种）。
- **设置页**：外观、默认编辑器（自动识别本机装了哪些）、日志与诊断、备份、数据与环境、
  GitHub 绑定预留接口。
- **功能介绍**：设置页版本号下面进入，按版本列出每一版多了什么、修了什么。
- 任务详情：进度改成**进度条**（点一下 +10，也可以拖动、方向键微调）。
- 日志页：可以一键清空历史；浏览器自身的无害告警降级显示，不再混在错误里。

### 调整

- 全书界面**空状态统一**：用「开启的箱子」图标并居中，替代原来一行干巴巴的字。
- 日历的日期数字与柱状图数字调大，日期底色的区分度拉开（一眼能分出休息日）。
- **下线「界面密度」切换**：看着鸡肋，固定为舒适尺寸（控件 42px、正文 14px）。

### 修复

- 跨项目列表（我的待办、搜索）里状态标签显示成"未知状态"。
- 功能介绍里「返回列表」之后再点「返回」，会退回刚才那个版本。
- 总览的六边形点不动（点它无法下钻）。
- 日志页没有日志时，分页栏跑到了工具栏下面。
- 输入框与下拉框偏小、同一行的按钮高度不一致。

### 数据与升级

- 新增一张表 `calendar_marks`（日历标记）。**首次启动会自动迁移**，原有数据不动。
- 测试版（未打包运行时）与正式版的数据一直分开存放，这次也一样：
  打包版用 `%APPDATA%\@pm-studio\desktop`，开发版用 `...\desktop-test`。

## 发版怎么做（给自己的清单）

1. 改四处 `package.json` 的版本号（根 / shared / server / desktop，必须一致）。
2. 在 `data/whats-new.ts` 的 `RELEASES` **最前面加一条**，并在本文件顶部加一节。
3. 跑一遍：`tsc --noEmit`（根 + desktop）、`eslint .`、`vitest run`、
   `node packages/desktop/scripts/e2e/run.cjs`（**先把手动开着的应用关掉**，否则会抢实例）。
4. 打包：`pnpm --filter @pm-studio/desktop dist`，产物落在 `release/`。
5. 打包后再跑一遍**打包版**的端到端：`pnpm --filter @pm-studio/desktop e2e:packaged`
   —— 它验证的是"装出来的那个应用"，和开发运行时不是一回事。
